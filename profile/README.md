## Sodasoft

We build payment and security infrastructure, and the open-source tooling around it.

**[Payshen](https://www.payshen.com)** is payment orchestration: one integration for every payment provider a business uses, each payment routed to the provider most likely to approve it, and retried elsewhere only when that is safe. Payshen never holds funds; the merchant's own providers collect and pay out.

### Open source

| Repository | What it is |
| --- | --- |
| [payshen-php](https://github.com/meetsodasoft/payshen-php) | PHP client for the Payshen API: payments, captures, voids, refunds, events and webhook verification |
| [payshen-python](https://github.com/meetsodasoft/payshen-python) | Python client for the same API |
| [payshen-woocommerce](https://github.com/meetsodasoft/payshen-woocommerce) | WooCommerce plugin, also on [WordPress.org](https://wordpress.org/plugins/payshen-for-woocommerce/) |
| [PandaPayLens](https://github.com/ratomirjovanovic/PandaPayLens) | Local-first payment error decoder and transaction timeline for Stripe, Adyen and more |
